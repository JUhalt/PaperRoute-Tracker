# PaperRoute Tracker v0.6.0 — Workspace

**Released September 27, 2026.** PaperRoute v0.6.0 is the current Stable release. It brings PaperRoute into one window with pages, gives each manuscript a single page with one save step, and applies a calmer card-based design throughout. Nothing about your library changes: v0.6 uses the same Schema 6 library as v0.5.

## What's new

- **One window.** A left rail opens the **Board**, **Library**, **Journals**, **Reminders**, and **Import & Export** pages, with **Settings** and **Help** below. Ctrl+1 to Ctrl+5 open the pages, Alt+Left and Alt+Right go back and forward, and F1 opens the User Guide. The rail can collapse to icons for more room.
- **A page for each manuscript.** Overview, Authors, Versions, Submissions, and Readiness & Packets are tabs on one page, with one **Save** (Ctrl+S) and **Discard** bar. Leaving, switching manuscripts, or closing PaperRoute with unsaved changes asks first.
- **Submissions in place.** Each journal submission is listed beside the selected one, and its editorial history, reviewer responses, and correspondence are edited on the same page.
- **A clearer board.** Shelves are tabs with counts. Cards fill the window's width, open on a click, and show the stage, what needs attention, and the route so far. Needs Attention items filter the board.
- **Faster start.** Add Manuscript can read a Word or LaTeX title page and set a first deadline. An empty library opens on a welcome that explains each way in, and empty lists say what belongs there.
- **Library and Import & Export pages.** A sortable, filterable table of every manuscript, reusable authors and affiliations, and every way of bringing work in or taking it out on one page.
- **Fixes.** Names containing "&" keep it in every dialog, and so does the update prompt's **Download & Restart**. The response export preview no longer opens with the draft selected, and its Markdown reads as plain text. Muted text meets 4.5:1 contrast in Light and Dark.

## Upgrading

There is no data migration: v0.5 and v0.6 open the same library, and backups made by either version restore in both. Commands from the old **Data** menu now live on pages and under **Settings**; the User Guide's "Finding your way around" table lists each new location. The raw text of an exported Markdown response draft differs from v0.5 because it escapes less; the rendered result is the same.
