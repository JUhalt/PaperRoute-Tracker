# PaperRoute Tracker v0.3.0-rc.1 — The Route Release Candidate

PaperRoute v0.3 adds a historical spine for following a manuscript from working draft through submission, editorial decisions, revision, rerouting, and publication.

## What's new

- **Visual Route View** — see submissions, editorial decisions, reroutes, lifecycle state, and manuscript versions as one deterministic publication history.
- **Manuscript Version History** — track working, submitted, and revised snapshots without overwriting earlier versions.
- **Current State vs. Current Version** — distinguish where the manuscript is in the publication workflow from which manuscript snapshot you are actively working from.
- **Workflow-linked versions** — associate a version with the journal submission it was sent with, the editorial decision that prompted it, and an optional revision round.
- **Managed PaperRoute Library snapshots** — copy immutable historical versions into PaperRoute's managed library, link to original files, or keep metadata-only history.
- **Safe version deletion** — linked originals are never deleted; PaperRoute-owned snapshots are removed transactionally when the manuscript save succeeds.
- **Chronology and provenance** — real-world event dates remain separate from when PaperRoute learned or edited the record, so later metadata edits do not rewrite manuscript history.
- **Contextual workflow help** — concise `?` guidance explains Current State, Current Version, Journal manuscript ID, version dates, and workflow associations.
- **Route drill-down** — open a Route waypoint directly in the authoritative Manuscript Details record.
- **Recovery hardening** — damage or access problems in PaperRoute's internal managed-version staging area warn instead of preventing an otherwise valid manuscript database from opening.
- **Updater and responsive-layout polish** — cleaner release-note presentation and additional narrow/high-DPI hardening.

## Compatibility and safety

Existing manuscript libraries remain supported. PaperRoute continues to keep development data isolated from the standard profile, validates storage migrations before opening the library, preserves backups, and does not delete externally linked manuscript files.

## Known cosmetic issue

At some narrow/high-DPI main-window sizes, manuscript shelves may show an unnecessary horizontal scrollbar even when all controls remain reachable. This is cosmetic and does not affect manuscript data or workflow behavior.


This Preview build is intended for final installed-update, backup/restore, and clean-install certification before the Stable v0.3.0 release.
