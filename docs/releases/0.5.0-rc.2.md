# PaperRoute Tracker v0.5.0-rc.2 — Reviewer Response Workflow

This Preview candidate replaces v0.5.0-rc.1 for final certification. It contains everything in rc.1 plus one interface fix and updated documentation. v0.4.0 remains the current Stable release while installed, updater, and native display certification is completed.

## Changes since rc.1

- Literal ampersands now display correctly. Manuscript Details showed **Save  Close** and **DOI  Crossref Metadata...**; the same fix covers the Journal, Preprint & Project Links dialog, the **Data** menu (**Authors & Affiliations...**, **Publication & CV Export...**), the Version History summary, the version editor's managed-copy help, and the Settings notification help ([#67](https://github.com/JUhalt/PaperRoute-Tracker/issues/67), [PR #68](https://github.com/JUhalt/PaperRoute-Tracker/pull/68)).
- The User Guide's "What Comes After v0.5?" section reflects the updated roadmap: v0.6 Workspace UI, v0.7 Deadline Center, and v0.8 Route Analytics & Reports ([PR #66](https://github.com/JUhalt/PaperRoute-Tracker/pull/66)).

## Included

- Track reviewer/editor comments, actions, statuses, draft responses, manuscript locations, and working notes within an existing journal submission.
- Associate each item with a recorded editorial decision and an explicit revision round. Filter by status and reorder the complete item sequence.
- Preview and edit a Markdown response-to-reviewers draft before saving it. Export includes all matrix items and working notes, and does not modify the manuscript or record a resubmission.
- Preserve nested save/cancel boundaries and validate response references during save, recovery, migration, and portable restore.
- Keep manuscript shelf cards and their actions reachable after narrow/wide resizing and maximize/restore, with vertical scrolling retained.

## Before trying this candidate

The candidate uses Schema 6. Make a full portable backup with v0.4 before upgrading, and keep that pre-upgrade backup if you may return to v0.4. Restore v0.5 backups only with v0.5 or later; an older application's restore path can ignore reviewer-response fields. Excel remains a partial interchange format.

Use a disposable Windows test environment for candidate certification. The response workflow is entirely manual and requires no AI service or account. Save the matrix back to the manuscript working copy, then save Manuscript Details to persist it.
