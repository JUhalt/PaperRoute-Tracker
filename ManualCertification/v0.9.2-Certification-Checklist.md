# v0.9.2 certification checklist

One ordered list of everything the v0.9.2 certification ([#147](https://github.com/JUhalt/PaperRoute-Tracker/issues/147)) asks for, gathered from #147's gates, the [standing procedure](Release-Certification.md), and what each merged pull request left to certification. It is grouped by what has to be set up, so that each setting is changed once: the host first, then publication, then one session on the certification VM, then the close-out.

**How to use it.** Work down the list in order. Each line names where it comes from and what a pass looks like. Replace its `Result: not run` with what happened: pass or fail, the numbers, the evidence file names, or Narrator's words. A line that is skipped says why. When the list is done, post it to #147, which holds each result once (procedure step 9). Evidence JSON is preferred to screenshots (step 10), and no evidence folder goes under `%TEMP%`.

**Why the VM session comes after publication.** Procedure step 8 runs the installed-app gates on the published build, installed through the live updater or from the published Setup, not on a local candidate of the same commit. The maintainer's sign-off before the tag is the gate, so everything that can be checked without the published build comes first, on the host. A line that fails after publication, even one that "fails the release", is recorded on #147 at once; the maintainer then decides what follows, such as a v0.9.3 patch or withdrawing v0.9.2 from Stable, and #44 waits for that decision.
