# v0.5 Reviewer Response Workflow — development evidence

This is an unreleased development checkpoint for [issue #27](https://github.com/JUhalt/PaperRoute-Tracker/issues/27). PaperRoute **v0.4.0 remains the current Stable release**.

## Implemented increment

- Reviewer/editor response items remain inside an existing journal submission.
- Each item uses an existing editorial decision and an explicitly entered positive revision-round number.
- Reviewer label, comment, action, status, draft response, manuscript location, and notes are editable.
- Status filtering, complete-sequence reordering, and an editable Markdown preview/save are available.
- Decision deletion is guarded while response items still reference that decision.
- Matrix, item editor, export, submission metadata, outer Manuscript Details, repository recovery, and portable restore preserve independent copies and save/cancel boundaries.
- Schema 5 to 6 migration validates existing data before advancing the marker; older applications are rejected from newer libraries rather than silently discarding the response collection.
