# One line per symbol, sorted (ordinal), "<documentation ID>;<reason>":
#   T:<type>   the whole type, every member allowed; only for a type that holds data in memory and touches no file, folder,
#              network, registry, process or key store. The reason starts "in memory only: " and says what was read.
#   M:/F:<member>  one method (property and event accessors included) or field of any other type. The reason says what it is
#              and why it cannot change a library on disk, or, for the few that write, what confines the write to the isolated session.
# A second category, WRITES THE PERSON'S STORAGE: start-up and recovery only; the owner is named in lifted-bans.txt. Such a line's reason
#              starts "WRITES THE PERSON'S STORAGE: " and says what it writes; EachLiftedBanHasOneOwner fails it unless lifted-bans.txt lists
#              the member, or its whole type, with its one owner file (start-up design 2.8).
# A type named only in the parameters of a listed member (ManagedLibraryService) needs no line of its own: naming it runs none of its code.
